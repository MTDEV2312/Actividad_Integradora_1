## Tecnologías Utilizadas
- **HTML5:** Marcado semántico (`header`, `nav`, `main`, `section`, `figure`, `footer`).
- **CSS3:** Variables personalizadas (`:root`), Flexbox, CSS Grid y Media Queries.
- **Google Fonts:** Tipografía *Bebas Neue*.
- **Git & GitHub:** Control de versiones.

## Instrucciones para Visualizar el Proyecto

### Opción 1: Apertura directa
1. Descargar o clonar el repositorio:
   ```bash
   git clone https://github.com/MTDEV2312/Actividad_Integradora_1.git
   ```
2. Abrir la carpeta del proyecto.
3. Hacer doble clic sobre el archivo `index.html` para abrirlo en cualquier navegador web moderno (Chrome, Edge, Firefox, Brave).
